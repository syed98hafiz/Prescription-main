📋 How to share templates with colleagues

Templates are standard JSON files — you can share them via WhatsApp, email, Google Drive, or any file-sharing method.

  1. Sender: Open builder → ⋮ menu → Export defaults (or Local template → Save)
  2. Share the downloaded .json file
  3. Receiver: Open builder → ⋮ menu → Import defaults (or Local template → Load)
